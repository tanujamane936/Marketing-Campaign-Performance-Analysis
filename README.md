# Marketing Campaign Performance Analysis

Analysis of 500 marketing campaign records (Dec 2024 – Jun 2025) across 5 channels 
and 4 regions, built to evaluate spend efficiency, conversion performance, and 
profitability using Excel Pivot Tables and dashboards.

## Overview

This project analyzes campaign-level marketing data to identify which channels and 
regions deliver the best return on ad spend. It covers data cleaning, KPI 
calculation, pivot-table summarization, and dashboard-style reporting.

## Dataset

- **Records:** 500 campaigns
- **Time period:** December 2024 – June 2025
- **Channels:** Google Ads, Facebook, Instagram, LinkedIn, Twitter
- **Regions:** North, South, East, West
- **Raw fields:** Campaign ID, Date, Channel, Region, Budget, Spend, Impressions, 
  Clicks, Conversions, Revenue
- **Derived metrics:** CTR (Click-Through Rate), CPC (Cost per Click), CPA (Cost 
  per Acquisition), ROAS (Return on Ad Spend), Profit, Profit Margin %

## Key Analysis

- **Monthly trends** — Spend vs. Revenue by month (Dec 2024–Jun 2025)
- **Channel performance** — Total spend, revenue, and average ROAS by channel
- **Regional performance** — Conversions and budget allocation by region
- **Profitability** — Profit and profit margin by channel to flag under/over 
  performing campaigns

## Tools Used

- Microsoft Excel (Pivot Tables, Pivot Charts, Dashboards)
- KPI formulas: CTR, CPA, CPC, ROAS, Profit Margin %

## Files

| File | Description |
|---|---|
| `Marketing_Campaign_Data.xlsx` | Raw + processed campaign dataset with pivot tables |

## Key Insights

- Instagram and Google Ads generated the highest profit among all channels.
- South region led in conversions; West lagged behind on budget efficiency.
- Campaigns with CPA above ~$40 consistently show negative profit margins — 
  a threshold worth flagging in future campaign planning.
